# 데이터 처리 설명 · Nookrew 0.1.9

이 문서는 구현의 기술 설명이며 공식 디렉터리 제출에 필요한 최종 법적 개인정보 정책을 대신하지 않습니다.

사무실은 선택한 로컬 폴더의 실제 Codex 세션·활동·명시적 토큰 기록을 관찰하고 프로젝트 파일을 읽습니다. 최근 대화는 공식 Codex app-server로 조회합니다. 사용자가 보내기를 누른 메시지는 기존 Codex 계정/원래 세션으로 전달되며 OpenAI의 이용 조건과 데이터 처리가 적용됩니다.

사무실·업무·문서 코멘트·SNS 초안 등은 선택한 프로젝트의 로컬 SQLite/설정에 저장됩니다. 꾸미기·테마는 브라우저 저장 공간에 보관됩니다. 종료는 파일이나 기록을 삭제하지 않습니다. 제거하려면 종료 후 필요한 기록을 백업하고 해당 프로젝트의 .aiorchestra 폴더 및 브라우저 설정을 사용자가 관리해야 합니다. 실행 중 전체 폴더를 삭제하지 마세요.

로컬 서버는 literal loopback 주소로 열립니다. 기본 사무실 코드에는 miscforge로 사용 기록을 전송하는 별도 분석 수집기가 없습니다. Codex/운영체제/선택한 외부 서비스의 데이터 처리까지 이 설명이 보장하지는 않습니다.

선택 기능인 Threads/Instagram 연결은 사용자가 자격 증명을 등록하고 명시적으로 승인·게시할 때 Meta API를 이용합니다. SNS 계정 실제 수용 검증은 아직 미완료입니다. 사용자 이미지 팩은 데이터로 취급하며 실행 코드나 외부 URL을 가져오지 않습니다.
