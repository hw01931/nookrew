# Nookrew 0.2.0-beta.3

AI에게 일을 맡긴 다음, 무엇을 확인하고 어디로 돌아갈지 한곳에서 봅니다.

- **업무와 반복작업**: 한 번만·반복해서·순서대로 중 고르면 필요한 입력만 나옵니다. 줄간격과 입력칸·카드 여백을 정리했습니다. 등록 성공 뒤 입력은 비우고, 실패하면 작성 내용을 보존합니다.
- **작업 확인**: 직접 확인한 결과와 실행 기록에서 찾은 검사를 구분합니다. AI에게 검사 부탁할 글을 검토하고 복사할 수 있습니다.
- **변경 확인·저장 지점**: 넓은 화면에서 오가며, 되돌릴 때 어떤 영역의 파일이 복원·재생성·삭제되는지 먼저 봅니다.
- **처음 열 때**: 준비된 카드부터 보여 주고 큰 세션 기록을 나눠 읽습니다. 모든 프로젝트의 시작 속도를 보장하지는 않습니다.

Windows x64, macOS Apple Silicon·Intel, Linux ARM64·x64용 로컬 베타입니다. 별도 모델/API 키 없이 기존 Claude Code·Codex와 함께 사용합니다.

[설치 안내](https://github.com/hw01931/nookrew#설치--windows--macos--linux-무료-베타)

업무 예약은 목록에 할 일을 생성하며 메시지 전송은 사용자가 합니다. 저장 지점은 프로젝트 파일 대상이며 운영 DB·이미 배포한 앱을 복구하지 않습니다. 실제 비개발자 사용 시험과 macOS/Linux의 Codex Desktop 계정 대화·전체 UI 수용은 아직 검증하지 않았습니다. 베타 피드백을 환영합니다.
