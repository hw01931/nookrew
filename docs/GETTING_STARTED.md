# Nookrew · 누크루 사용법

AI에게 일을 맡기고 채팅창만 기다리는 시간이 심심해서, 함께 일하는 동료들을 작은 사무실로 보고 싶었습니다. 누크루는 기존 Codex를 사용하면서 옆에 여는 로컬 사무실입니다.

## 지원 환경

Windows x64, 설치된 Codex, 기존 ChatGPT 로그인, 로컬 실행 도구가 있는 Codex 대화. 프로젝트 등록은 필수가 아니지만 선택한 로컬 작업 폴더는 필요합니다. ChatGPT 웹·로컬 실행 없는 일반 대화, macOS·Linux는 현재 지원 범위가 아닙니다.

## 설치 및 시작

검증한 배포 패키지를 풀고 Codex에 해당 marketplace 폴더를 설치해 달라고 요청합니다. 공식 CLI에서는 codex plugin marketplace add <배포 폴더의 절대경로> 후 codex plugin add moyo-office@moyo-local를 사용합니다. 공개 패키지의 identity가 달라질 경우 그 패키지 안내를 따릅니다. 별도 Node/npm 설치는 필요하지 않습니다.

플러그인 선택 메뉴에서 Nookrew를 선택하고 시작 또는 start라고 입력합니다. 실제 @멘션을 선택하세요. 텍스트만 쓰는 것이 플러그인 선택과 항상 같지는 않습니다. 최초 실행 권한 검토는 Codex 호스트 정책을 따릅니다.

## 사무실에서

- 캐릭터: 최근 실제 대화 조회 및 원래 Codex 직원에게 메시지 접수. 응답 완료 캐릭터의 대화가 로드되면 쉬는 중으로 확인 처리합니다. 접수와 실행 완료는 다릅니다.
- 직원 목록: 이름·담당·외형과 사용량을 확인합니다. 캐시 포함 누적 처리량은 생성한 글의 양·청구액·성과가 아닙니다.
- 사무실 꾸미기: 가구 배치 / 테마·색상 / 내 에셋. 배치는 미리보기 후 저장하며 취소는 기존 배치를 보존합니다. 테마 적용은 별도 저장입니다.
- 잠깐 놀기: 기억 맞추기 또는 틱택토를 혼자/쉬는 캐릭터와 합니다. 상대는 로컬 규칙이며 실제 직원 모델 호출이 아닙니다. 직원이 바빠지면 함께 하던 게임이 중단됩니다.
- 컴퓨터·자료실: 실제 프로젝트 파일·변경 내역·문서와 코멘트를 확인합니다. 파일 접근은 선택한 root 경계 안에서 처리합니다.

## 문제 해결

실행 도구 없음: 로컬 Codex 대화에서 열어야 합니다. 로그인 재연결 문제로 단정하지 않습니다. EFAULT: 실행기는 IPv4 재시도/로컬 IPv6 대체를 사용합니다. 화면 연결 거부: 실제 실행기가 반환한 URL을 사용하세요. 전송 UNKNOWN: 자동 재전송하지 말고 원래 Codex에서 확인하세요. 승인·중단: 원래 Codex 창에서 처리합니다.

서버 종료는 사무실 종료 버튼입니다. 종료는 파일과 프로젝트 기록을 삭제하지 않습니다.
