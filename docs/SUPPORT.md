# 지원 · Nookrew

문제 제보는 이 저장소의 Issues를 이용하세요. Windows/Codex 버전, 실행 단계, 오류 코드만 먼저 적어주세요. 인증키·대화 원문·전체 프로젝트 파일을 공개 이슈에 첨부하지 마세요.

실행 도구 없음: 로컬 Codex 대화에서 실행해야 합니다. 프로젝트 등록이나 인증 문제로 단정하지 않습니다.
EFAULT: 실행기가 제한된 재시도와 IPv6 loopback 대체를 사용합니다. 반환한 실제 URL을 사용하세요.
전송 UNKNOWN: 자동 재전송하지 않고 원래 Codex에서 확인합니다.

무료 베타이며 응답 시간이나 특정 복구 시간은 보장하지 않습니다. Claude/macOS/Linux/웹 실행 지원을 완료했다고 주장하지 않습니다.
