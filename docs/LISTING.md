# Nookrew 목록 소개 초안

게시자: miscforge / 잡동사니대장간
소개: 일단 만들고 생각합니다.
제품: Nookrew · 누크루
부제: Your little AI office
가격 방향: 무료 베타. Codex 이용 조건·계정 사용량은 별도.
지역: 포털에서 지원하는 모든 국가.

AI에게 일을 맡기고 채팅창만 기다리는 시간이 심심했나요? 여러 세션의 상태를 놓치지 않고, AI 동료들이 일하는 작은 사무실로 보고 싶어서 누크루를 만들었습니다.

누크루는 기존 Codex를 대체하지 않는 Windows용 로컬 사무실 패널입니다. 같은 작업 폴더의 실제 Codex 세션을 직원으로 보여주고, 최근 대화를 확인하거나 원래 직원에게 메시지를 접수합니다. 프로젝트 문서와 파일 변경을 확인하고, 사무실을 꾸미고, 기다리는 동안 짧은 로컬 게임을 할 수 있습니다.

실제 관찰한 상태만 표시합니다. 모르는 사용량을 0으로 만들지 않으며 응답 종료와 검증 완료를 구분합니다. 게임은 모델 호출을 하지 않습니다. 승인과 중단은 원래 Codex에서 처리합니다.

지원: Windows x64 / 로컬 Codex 및 ChatGPT 로그인 / 로컬 실행 가능한 대화. Claude 연결, macOS/Linux, ChatGPT 웹 실행은 지원 완료가 아닙니다. 배포 서명·공개 검색·새 PC 수용은 각각 별도로 검증해야 합니다.

미확정 공개 필드: 웹사이트·지원·개인정보·이용약관 HTTPS URL, 게시자 인증, 포털 심사 자격/상태. 로컬 MCP 공개 제출은 승인 파트너 제한이 있다(공식 docs 2026-10-15 확인). 공개용 desktop skills 패키지는 실행기 경로를 사용해 같은 사무실을 열며 공개 MCP 제공과 구분한다.
