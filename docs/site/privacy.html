이 방침은 miscforge가 배포하는 Nookrew 0.2.0 beta 무료 로컬 플러그인과 소개 사이트에 적용됩니다. 누크루를 이용하기 위한 별도 회원가입이나 개발자 운영 클라우드 계정은 없습니다.

로컬 정보 처리

선택한 작업 폴더의 파일·문서, Codex 세션 식별자·활동 상태·기록된 사용량을 읽어 사무실을 표시합니다. 최근 대화는 Codex 인터페이스로 조회합니다. 사용자가 편집한 문서·코멘트·업무 기록·전송 접수 기록과 설정은 로컬 프로젝트 저장소에 저장될 수 있습니다. 테마·꾸미기 설정은 브라우저 저장 공간에도 저장됩니다. 이 정보는 사무실 표시와 요청한 기능 수행에 사용됩니다.

개발자에게 자동 전송하지 않는 정보

기본 사무실에는 프로젝트 파일·대화·토큰 기록을 miscforge 서버로 자동 전송하는 분석 수집기가 없습니다. 로컬 프로그램이 정보를 읽는 것과 개발자가 그 정보를 수집하는 것은 다릅니다.

외부 서비스

사무실에서 보낸 메시지는 기존 Codex 계정과 원래 세션에 전달되며 OpenAI의 정책이 적용됩니다. 선택한 Threads/Instagram 연결을 사용하면 요청한 게시·답장 등의 콘텐츠가 Meta 서비스로 전달됩니다. 이 선택 기능의 실제 계정 검증은 아직 미완료입니다. GitHub는 사이트 방문 및 저장소/이슈 이용에 관한 정보를 자체 정책에 따라 처리할 수 있습니다. 누크루의 로컬 정책이 이들 서비스의 처리를 대체하지 않습니다.

보관·삭제

로컬 기록은 자동으로 종료와 함께 삭제되지 않습니다. 사무실 종료 후 필요한 자료를 백업하고 해당 프로젝트의 .aiorchestra 저장 폴더와 사무실 URL의 브라우저 사이트 데이터를 관리할 수 있습니다. .aiorchestra 전체 삭제는 기록과 설정을 잃게 하므로 필요한 파일을 먼저 확인하세요. Codex 원본 대화나 외부 SNS 게시물은 해당 서비스에서 따로 삭제해야 합니다.

지원 요청과 권리 행사

https://github.com/hw01931/nookrew/issues 에서 지원을 요청할 수 있습니다. 공개 이슈에는 비밀키·카드정보·대화 원문·개인 파일을 올리지 마세요. 공개 이슈와 댓글은 GitHub에 남으며 해당 플랫폼의 수정·삭제 기능과 정책을 따릅니다. 민감한 정보가 포함된 요청은 공개 게시하지 마세요.

English summary

Nookrew processes selected project and Codex session information locally to provide the office. It has no default publisher analytics collector or separate publisher cloud account. Messages use your existing Codex account; optional social actions use their external provider. Local records persist until you remove them. GitHub hosts this website and support issues under its own privacy practices. For help use the repository Issues without posting sensitive information.
