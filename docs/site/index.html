설치 / Install

Windows·macOS·Linux의 로컬 Codex에 다음 문장을 보내세요: https://github.com/hw01931/nookrew 이 저장소의 Nookrew 플러그인을 사용자 공용으로 설치하고 현재 작업 폴더의 사무실을 열어줘. 설치 후 Nookrew를 선택하고 시작 또는 start라고 입력하세요. 한 번 설치하면 다른 로컬 폴더에서도 사용합니다.

Codex만 준비하세요

누크루 자체 회원가입·API 키·별도 Node/npm 설치는 필요하지 않습니다. Codex 설치와 기존 로그인, 로컬 실행 가능한 대화가 필요합니다. 첫 설치·실행은 호스트의 권한 확인을 따릅니다.

무료 다중 OS 베타

실제 세션 상태와 최근 대화, 원래 Codex 세션에 메시지 접수, 프로젝트 자료와 변경 확인, 사무실 꾸미기와 로컬 게임. 접수·응답 종료·검증 완료는 다릅니다. Windows x64·macOS Apple Silicon/Intel·Linux ARM64/x64의 런타임을 제공합니다. 실제 Codex Desktop 대화/UI 수용과 OS 런타임 검증은 구분합니다. ChatGPT 웹·Claude 연결은 아직 지원 완료가 아닙니다.
