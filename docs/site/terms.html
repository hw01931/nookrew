이 약관은 miscforge의 Nookrew 무료 Windows 베타 이용 조건을 설명합니다. 누크루는 Codex의 공식 제품이 아닌 독립적인 사무실 플러그인입니다.

무료 베타와 외부 서비스

누크루 0.1.9는 무료로 제공되며 자체 결제 기능이 없습니다. Codex 및 선택한 외부 서비스의 이용 조건·비용·사용량 제한은 각 제공자가 정합니다. 현재 무료 베타 이용에 미래 유료 기능 구매 의무는 없습니다.

이용 범위

Windows x64와 로컬 실행 가능한 Codex 환경을 지원합니다. 사용자는 접근 권한이 있는 폴더·계정·자료만 연결하고, 보내는 메시지·문서 수정·외부 게시 내용을 확인해야 합니다. 승인과 중단은 원래 Codex에서 처리합니다. 표시된 완료 상태가 코드 검증이나 업무 성과를 보장하지 않습니다.

제한과 복구

베타에는 오류·호스트 호환성 차이·기능 변경이 있을 수 있습니다. 중요한 파일은 백업하세요. 응답 시간·중단 없는 서비스·모든 기기 호환을 보장하지 않습니다. 이 설명은 적용 법률에 따른 사용자의 권리를 제한하지 않습니다.

콘텐츠와 라이선스

사용자 콘텐츠의 권리를 누크루 이용만으로 개발자에게 이전하지 않습니다. 타인의 자료·API는 필요한 권한을 가진 범위에서 이용하세요. 배포 코드와 번들 에셋은 각 파일 및 서드파티 라이선스를 따르며, 무료 사용이 모든 파일의 무제한 재배포 허락을 뜻하지 않습니다.

종료·변경·지원

사무실을 닫거나 플러그인을 제거해 이용을 중단할 수 있습니다. 종료나 제거가 모든 로컬·외부 기록을 자동 삭제하지는 않습니다. 정책 변경은 이 사이트의 날짜와 저장소 변경 내역으로 안내합니다. 지원은 GitHub Issues에서 제공하며 고정 처리 시간을 약속하지 않습니다.
