문제 제보

https://github.com/hw01931/nookrew/issues 에 Windows/Codex 버전, 재현 단계, 오류 코드를 적어주세요. 비밀키·개인 대화·전체 프로젝트 파일은 공개 게시하지 마세요. 응답·복구 시간은 보장하지 않습니다.

실행 오류

로컬 실행이 가능한 Codex 대화에서 열어야 합니다. 실행기가 반환한 실제 loopback URL을 사용하세요. EFAULT는 제한된 재시도와 IPv6 대체를 사용합니다. 메시지 전송 UNKNOWN은 원래 Codex에서 확인하고 자동 재전송하지 마세요.

Known limitations

Cross-platform runtime beta. Official directory submission is separate from Git installation. No guaranteed support response time. Report minimal reproduction details on GitHub Issues without credentials or private content.
