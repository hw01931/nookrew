## 사진 순서와 게시 상태

첫 글은 실제 사무실 전체 1장, 답글은 꾸미기·게임 실제 화면 2장. 설치는 복사 가능한 텍스트. 거대한 홍보 문구나 가짜 화면은 붙이지 않는다. OS 지원 문구는 실제 릴리스 검증 결과를 따른다. 공식 디렉터리 등록 완료라고 쓰지 않는다. 원고와 사진 준비이며 실제 게시하지 않았다.
