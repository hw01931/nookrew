# miscforge · Nookrew 첫 공개 글

## 1 / 만든 이유

AI한테 일 시켜놓고, 제가 채팅창 앞에서 대기 근무하고 있더라고요.

여러 세션을 켜면 누가 일하는 중인지, 누가 끝났는지도 탭을 하나씩 열어봐야 하고요. 무엇보다 텍스트만 보고 기다리는 게 좀 심심했습니다.

그래서 AI 동료들이 일하는 작은 사무실을 만들었습니다.
Nookrew, 누크루입니다.

## 2 / 무엇이 실제로 되나

Codex는 평소처럼 씁니다. 옆에는 작은 사무실을 켜두고요.

실제 Codex 세션이 직원으로 보이고, 일하는 중인지 응답을 마쳤는지 확인할 수 있습니다. 캐릭터를 누르면 최근 대화를 보고 원래 세션에 메시지도 보낼 수 있어요.

사무실과 가구도 꾸미고, 기다리는 동안 짧게 게임도 합니다. 직원 캐릭터와 하는 게임은 로컬 규칙으로 돌아가서 모델을 호출하지 않습니다.

성능이 몇 배 좋아지는 마법은 아닙니다. 기다리는 화면을 조금 덜 삭막하게 만들고 싶었습니다.

## 3 / 써보기

Windows에서 로컬 실행이 가능한 Codex 대화로 사용합니다. 한 번 설치한 뒤 플러그인을 선택해서 이렇게 요청하세요.

@Nookrew 시작
또는
@Nookrew start

Codex 안의 브라우저 패널에 사무실이 열립니다. ChatGPT 웹·일반 대화처럼 로컬 실행 도구가 없는 환경에서는 시작할 수 없습니다.

지금은 무료 베타입니다. 공개 다운로드가 실제로 열린 뒤 첫 댓글에 검증한 링크를 붙입니다. 아직 공개 검색 등록이나 모든 PC 지원을 완료했다고 쓰지 않습니다.
