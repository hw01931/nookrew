# 개인 에이전트로 사무실 에셋 만들기

에셋은 데이터이며 코드/스크립트가 아니다. 규격 1의 JSON 팩에 PNG를 data URL로 담는다. 가져오기→이미지 검사→미리보기→배치·에셋 저장 후 적용한다. 최대 12개 에셋, 팩 2,200,000자, 개별 이미지 data URL 700,000자, 이미지 한 변 최대 2048px다. 로컬 저장 용량이 부족하면 기존 저장 상태를 유지하며 오류를 보여준다.

## 제작 요청 예시

자신의 Codex/Claude Code에 이 문서와 다음 요구를 전달한다.

> 이 프로젝트의 docs/OFFICE_ASSETS.md 규격에 맞춰 귀여운 고양이 직원과 화분을 만들어줘. 캐릭터는 등각 사무실 시점으로 방향과 발 위치를 통일하고, 4×4 PNG 시트로 제작해줘. 가구는 같은 시점의 투명 PNG로 만들어줘. manifest.json과 PNG를 같은 폴더에 저장한 뒤 office-asset-pack.cjs로 JSON 팩을 만들어줘. 에셋은 직접 만들거나 사용 가능한 라이선스를 확인해줘.

에이전트의 이미지 생성 능력/모델은 별도 도구다. 사무실이 이미지를 생성하거나 유료 모델을 자동 호출하지 않는다.

## 캐릭터 시트

정확히 같은 크기의 4열×4행이다. 가로·세로는 각각 64~2048px, 4의 배수. 투명 배경을 권장한다.

| 행 | 보는 방향 |
|---|---|
| 0 | 남동쪽(SE) |
| 1 | 남서쪽(SW) |
| 2 | 북동쪽(NE) |
| 3 | 북서쪽(NW) |

| 열 | 동작 |
|---|---|
| 0 | 서 있기 |
| 1 | 걷기 A |
| 2 | 걷기 B |
| 3 | 앉기 |

각 셀은 화면의 80×100 영역으로 표시된다. 발 기준점을 셀 아래 중앙에 맞추고 머리/손/발을 셀 밖으로 내보내지 않는다. 앉는 프레임도 동일 기준점에 맞춘다. 자체 가구별 별도 앉기/가림 anchor와 새로운 행동 프레임은 규격 1에서 제공하지 않는다. 저장 후 직원 상세의 캐릭터 선택에 `user-<id>`가 나타난다. 기존 직원의 이름/권한/실제 업무 상태는 바뀌지 않는다.

## 가구

`w`, `h`: 바닥 격자에서 차지하는 크기(각 1~3칸). `solid`: 이동을 막는지. 회전은 0/90/180/270도이며 홀수 quarter-turn에서 바닥 영역의 가로·세로를 바꾸고, 그림을 자동으로 다른 방향으로 재생성하지 않는다. 방향별 가구 그림은 별도 에셋으로 만든다.

그림 아래 중앙은 가구의 바닥 기준점이다. 규격 1의 가구는 장식/충돌용으로, 추가 의자에 직원이 자동으로 앉거나 사용자 지정 도구 행동을 실행하지 않는다. 기본 책상·소파·책장 등은 공통 world 좌표 변환으로 그림·좌석·경로를 함께 이동/회전한다. 추가 이미지 가구의 별도 앉기 행동은 기본 가구 동작으로 추측하지 않는다. 필수 좌석·벽·가구와 겹치거나 필수 좌석 접근을 끊는 배치는 거부한다. 추가 가구는 최대 30개다.

## 파일을 팩으로 묶기

PNG 파일은 manifest의 폴더 아래에 둔다. 외부 경로/링크/하드링크는 허용하지 않는다.

```json
{
  "schemaVersion": 1,
  "assets": [
    {"id": "cat", "kind": "character", "name": "고양이 직원", "imageFile": "cat.png"},
    {"id": "fern", "kind": "furniture", "name": "고사리", "imageFile": "fern.png", "w": 1, "h": 1, "solid": true}
  ]
}
```

```powershell
node scripts/office-asset-pack.cjs my-assets/manifest.json my-assets/office-pack.json
```

이 도구는 PNG 헤더에서 캐릭터 크기를 읽고 규격을 검사한다. 브라우저 가져오기 단계가 실제 이미지 디코딩과 크기를 다시 검사한다. 사무실 꾸미기→내 에셋 팩 가져오기에서 JSON 파일 선택 또는 붙여넣기→검사하고 미리보기→배치·에셋 저장. 파일 업로드를 지원하지 않는 호스트에서는 JSON 붙여넣기를 쓴다.

팩은 기존 사용자 팩을 대체한다. 사용 중인 가구 ID가 사라지는 대체는 거부하므로 해당 가구를 먼저 제거한다. 사라진 캐릭터 ID는 기본 캐릭터로 돌아간다. 내보낸 PNG의 저작권·라이선스는 제작자가 확인해야 한다.
