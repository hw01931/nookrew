# 브랜드 검토

## 기준 찾기
프로젝트 규칙, memory.search("브랜드", "말투", "용어"), record.search로 브랜드 지침을 찾는다. 없으면 "브랜드 지침 없음: 일반 검토"라고 밝히고 명확성·일관성·전문성만 본다.

## 지침이 있을 때
- 말투: 정해진 성격(예: 친근하지만 가볍지 않게)과 맞는가, 중간에 말투가 바뀌지 않는가.
- 용어: 권장 용어를 쓰는가, 피할 말이 있는가, 제품·기능 이름 표기가 맞는가.
- 메시지: 핵심 메시지와 맞는가, 승인된 내용과 어긋나는 주장은 없는가.
- 표기: 숫자·날짜·단위 형식, 약어는 처음에 풀어 썼는가, 제목 형식.

## 지침이 없을 때
- 명확성: 첫 문단에 요점이 있는가, 문장이 짧고 분명한가, 모호한 지시어가 없는가.
- 일관성: 같은 것을 같은 말로, 말투·형식이 처음부터 끝까지 같은가.
- 전문성: 오탈자, 어색한 문장, 대상에 맞는 말투.

## 항상 보는 위험
- 근거 없는 최상급("최고", "가장 빠른", "유일한")과 수치.
- 면책 문구가 필요한 금융·건강·보장 주장.
- 경쟁사 비교(공개 근거가 있는가).
- 출처·동의 없는 후기·인용.
- 다른 글을 거의 그대로 옮긴 부분(저작권).
- 차별·배제 표현, 특정 집단을 낮추는 말.
법률 판단은 하지 않는다. 위험을 표시하고 사람 검토를 권한다.

## 결과(artifact.write type report)
- 총평: 맞는 정도, 강점 1~2개, 가장 중요한 개선 1~2개
- 문제 표: 내용 · 위치(문장 인용) · 심각도(높음: 말투 위반·법적 위험 / 중간: 지침 불일치 / 낮음: 취향) · 제안
- 고쳐 쓰기: 심각도 높은 3~5곳의 원문 → 수정안
- 위험 목록(따로)
지침을 새로 정리해 달라는 요청이면 성격 3~5개(이렇다/이렇지 않다/예문), 채널별 말투, 용어 표로 쓴다.
