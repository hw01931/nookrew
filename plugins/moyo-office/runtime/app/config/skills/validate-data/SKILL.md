# 분석 검증

## 1. 방법
- 질문에 맞게 답했는가, 다르게 읽힐 여지는 없는가.
- 데이터·기간·대상이 맞는가, 빠진 대상은 없는가(탈퇴·실패한 경우).
- 지표 정의가 분명하고 기간마다 같은가. 비교 기간의 길이가 같은가.

## 2. 점검표
- 출처: 어느 기록·시트·주소인지, 언제 기준인지 적혀 있다.
- 완전성: 빠진 기간·집단이 없다. 빈 값을 어떻게 다뤘는지 적혀 있다.
- 중복: 같은 건이 두 번 세어지지 않았다(표를 이을 때 행이 늘지 않았나).
- 계산: 비율의 분모가 맞고 0이 아니다. 부분합이 전체와 맞는다. 비율 합이 100% 근처다.
- 상식: 크기가 말이 되는가, 0%·100%·딱 떨어지는 수가 이상하지 않은가, 50% 넘는 변화에 이유가 있는가.
- 표현: 막대는 0부터, 축 이름·단위, 제목이 내용과 맞음, 숫자 형식 일관.

## 3. 흔한 함정
- 평균의 평균: 집단 크기가 다르면 원자료로 다시 계산한다.
- 덜 끝난 기간 비교: 이번 달 중간값을 지난달 전체와 비교하지 않는다.
- 분모 바뀜: 정의가 바뀌면 비율을 비교할 수 없다.
- 생존 편향: 남아 있는 것만 보면 결론이 틀린다. "누가 빠졌나?"를 묻는다.
- 결과로 나눈 집단: "완료한 사람이 더 오래 남는다"는 당연하다.
- 상관을 원인으로, 적은 표본, 여러 번 시험해 좋은 것만 고르기, 합치면 뒤집히는 추세(심슨 역설).

## 4. 재계산
핵심 숫자 2~3개를 다른 방법으로 다시 계산한다(sheet 수식). 맞으면 "확인", 다르면 "불일치"와 차이를 적는다. 다시 계산하지 못한 것은 "미확인"이다.

## 결과
artifact.write type report:
- 판정: 공유 가능 / 한계를 밝히고 공유 / 수정 필요
- 문제 목록(심각도 높음/중간/낮음 · 내용 · 영향 · 고치는 법)
- 재계산 결과(지표 · 확인/불일치/미확인)
- 공유할 때 반드시 밝힐 한계
자기가 만든 분석이면 "자기 검토"라고 쓴다.
