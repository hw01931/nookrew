# 디자인 평가

## 순서
1. 첫인상(2초): 눈이 먼저 가는 곳이 맞는가, 목적이 바로 보이는가.
2. 사용성: 사용자가 목표를 끝낼 수 있는가, 누를 수 있는 것이 분명한가, 불필요한 단계가 없는가.
3. 정보 위계: 읽는 순서가 분명한가, 강조가 맞는 곳에 있는가, 여백이 정리를 돕는가.
4. 일관성: 프로젝트 규칙·디자인 토큰을 따르는가, 같은 요소가 같게 동작하는가.
5. 접근성: 대비, 누르는 영역 크기, 글자 크기, 이미지 대체 텍스트.

## 피드백 쓰는 법
- 구체적으로: "버튼이 메뉴와 경쟁한다"처럼. "레이아웃이 헷갈린다"는 쓰지 않는다.
- 이유를 원칙이나 사용자 목표와 연결한다.
- 문제만 말하지 말고 대안을 제안한다. 잘 된 점도 적는다.
- 단계에 맞춘다: 초기 탐색과 마무리 단계의 피드백은 다르다.
