# 기획서(PRD)

## 목차
1. 문제: 누가 어떤 상황에서 무엇이 불편한가(한 단락).
2. 사용자와 대표 과업: 시작점 → 핵심 행동 → 결과 확인 → 실패했을 때.
3. 목표와 비목표: 이번에 하는 것과 하지 않는 것.
4. 화면과 흐름: 화면 목록, 흐름은 ```mermaid flowchart.
5. 상태: 빈 화면, 불러오는 중, 오류, 권한 없음.
6. 완료 기준: 확인할 수 있는 문장으로(검증 기준 시험이 될 것).
7. 미정 사항과 결정 필요.

## 주의
