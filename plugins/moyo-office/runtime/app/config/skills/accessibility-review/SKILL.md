# 접근성 점검 (WCAG 2.1 AA)

## 기준
- 1.1.1 의미 있는 이미지에 대체 텍스트.
- 1.3.1 제목·목록·표·라벨을 의미 있는 태그로 표현.
- 1.4.3 글자 대비 4.5:1 이상(큰 글자 3:1). 1.4.11 버튼·입력 테두리 등 3:1.
- 2.1.1 모든 기능을 키보드로. 2.4.3 초점 순서가 논리적. 2.4.7 초점 표시가 보임.
- 2.5.5 누르는 영역 44×44px 이상.
- 3.3.1 오류를 글로 알림. 3.3.2 입력마다 라벨.
- 4.1.2 모든 컨트롤에 이름·역할·값.

## 자주 놓치는 것
대비 부족, 라벨 없는 입력, 키보드로 못 가는 요소, 모달 초점 갇힘, 200% 확대 시 깨짐.

## 확인 방법
코드가 있으면 project.read로 HTML을 읽고 위 기준을 하나씩 대조한다. 자동 검사로는 문제의 일부만 잡히므로 키보드만으로 쓰는 흐름을 글로 따라가 본다.
