# 마케팅 콘텐츠 작성

## 시작 전
대상 독자, 목적(알리기·가입·구매), 채널, 핵심 메시지 하나, 브랜드 말투(프로젝트 규칙·memory.search)를 확인한다. 없으면 가정을 적는다.

## 정직 규칙
- 통계·고객 후기·인용·수상·고객사 이름을 지어내지 않는다. 근거가 있으면 출처(기록 ID나 주소)를 달고, 없으면 [확인 필요: 고객 인용] 같은 빈칸으로 둔다.
- "최고", "유일", "1위"는 근거가 있을 때만. 경쟁사 비교는 공개 자료로 확인한 것만.
- 사실 조사는 web.search → web.fetch, 주소를 남긴다.

## 유형별 구조
- 블로그: 제목(핵심어 포함, 짧게) → 도입(문제·질문·장면) → 소제목 3~5개(한 절에 생각 하나와 예시) → 정리와 행동 유도 → 검색 요약문(한두 문장).
- SNS: 첫 줄에 눈길(질문·숫자·주장) → 요점 2~4개 → 할 일 하나 → 해시태그 3~5개(채널에 따라).
- 뉴스레터: 제목(짧게, 가치가 보이게) → 미리보기 문구(제목 반복 금지) → 내용 2~3덩어리 → 행동 유도 하나 → 수신 거부 안내.
- 랜딩 페이지: 핵심 이점 한 줄 → 부연 → 이점 3~4개 → 신뢰 근거(확인된 것만) → 자주 묻는 질문 → 행동 유도 반복.
- 보도자료: 사실 위주 제목 → 첫 문단에 누가·무엇을·언제·어디서·왜 → 세부와 인용(실제 발언만) → 회사 소개 → 문의처.
- 사례 글: 고객의 문제 → 해결 방법 → 결과(실제 수치만) → 고객 인용(동의받은 것만).

## 쓰는 법
- 기능보다 독자가 얻는 것. "당신/여러분"에게 말한다. 짧은 문단, 능동형.
- 전문 용어는 독자가 아는 것만. 과장·감탄사 남발 금지.
- 행동 유도는 동사로 시작하고 다음에 일어날 일을 말한다("무료로 시작하기"). 한 글에 주된 행동 하나.
- 검색: 핵심어 하나와 보조어 2~3개를 제목·첫 문단·소제목에 자연스럽게. 억지로 반복하지 않는다.

## 결과
artifact.write type report(또는 slides): 본문, 제목 후보 3개, 채널별 변형(필요하면), 확인이 필요한 빈칸 목록, 참고한 출처.
