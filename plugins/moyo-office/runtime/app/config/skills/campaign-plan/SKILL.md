# 캠페인 계획

## 입력 확인
목표, 대상, 기간(고정 날짜), 예산(없으면 예산 없이 계획하고 예산이 중요한 곳을 표시), 제품과 차별점, 이전 캠페인 결과(record.search). 빠진 것은 묻거나 가정으로 적는다.

## 틀: 목표 → 대상 → 메시지 → 채널 → 측정
- 목표: 인지 / 관심 / 전환 / 유지 / 추천 중 하나를 주목표로. 구체적·측정 가능·기한 있게. 목표 수치는 사용자가 정하거나 과거 기록에 근거할 때만 쓰고, 아니면 [목표치 확인 필요].
- 대상: "[역할]인 [누구]가 [문제]를 겪고 [바라는 것]을 원한다. 주로 [채널]에서 정보를 얻는다."
- 메시지: 핵심 한 문장 + 보조 메시지 3~4개(각각 근거). 순서: 왜 신경 써야 하나 → 해결책 → 왜 우리 → 할 일.
- 채널: 보유(블로그·이메일·SNS), 획득(보도·협업·커뮤니티), 유료(검색·SNS 광고). 대상이 있는 곳을 고른다. 채널마다 이유, 콘텐츠 형태, 노력(낮음/중간/높음).
- 측정: 주 지표 1개, 보조 지표 3~5개, 어떻게 잴지, 보고 주기.

## 결과물(artifact.write type plan)
1. 개요: 캠페인 이름 제안, 한 줄 요약, 목표
2. 대상과 고민
3. 메시지와 근거(근거 없는 것은 [근거 필요])
4. 채널 전략
5. 콘텐츠 일정 표: 주차 · 콘텐츠 · 채널 · 담당/메모 · 선행 조건(예: 랜딩 페이지 완성 후 광고 시작). 일정은 type diagram의 gantt로도 그릴 수 있다.
6. 필요한 콘텐츠 목록(필수/선택, 제작 시점)
7. 성과 지표
8. 예산 배분(예산이 있을 때, 예비비 포함)
9. 위험 2~3개와 대응
10. 다음 할 일과 사용자 결정이 필요한 것

## 이어서
콘텐츠 제작은 work.write로 업무를 나누고(task-splitting 참고), 각 글은 content-creation 스킬을 따른다. 경쟁 분석이 필요하면 competitive-brief.

## 주의
업계 평균·벤치마크 수치는 출처가 있을 때만 주소와 함께 쓴다. 성과 예측을 확정처럼 쓰지 않는다.
