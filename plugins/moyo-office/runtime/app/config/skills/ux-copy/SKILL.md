# 화면 문구

## 원칙
분명하게, 짧게, 같은 것은 같은 말로, 사용자에게 쓸모 있게. 사내 공식 문서 말투를 쓰고 과장·설명조를 피한다.

## 유형별
- 버튼: 동사로 시작하고 결과를 말한다("저장", "업무 맡기기"). "확인"·"제출"은 피한다.
- 오류: 무슨 일인지 + 왜 + 어떻게 고치는지. 예: "저장하지 못했습니다. 다른 곳에서 먼저 수정했습니다. 최신 내용을 확인하세요."
- 빈 화면: 무엇인지 + 왜 비었는지 + 시작하는 법. 예: "업무 없음 · 업무 맡기기로 시작하세요"
- 확인 창: 무엇을 하는지 구체적으로("파일 3개를 삭제합니다"), 되돌릴 수 없으면 적고, 버튼은 행동 이름으로("삭제"/"취소").
- 부제·캡션: 문장 대신 명사구("맡긴 일·진행 상태").

## 결과
추천 문구, 대안 2~3개(말투·쓰임), 이유. 바꿀 문구가 많으면 artifact.write type report로 표를 만든다.
