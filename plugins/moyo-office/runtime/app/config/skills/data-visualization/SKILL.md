# 데이터 시각화

## 그래프 고르기
| 보여줄 것 | 쓸 것 | 대안 |
| --- | --- | --- |
| 시간에 따른 변화 | 선 | 막대(기간이 적을 때) |
| 항목 비교·순위 | 막대(값 순 정렬) | 가로 막대(항목이 많을 때) |
| 전체 중 비율 | 누적 막대 | 원(6개 미만일 때만) |
| 분포 | 구간별 막대(히스토그램) | 사분위 표 |
| 두 수치 관계 | 산점도 | 표 |
| 단계별 이탈 | 단계 막대 | 흐름도 |

피할 것: 3D, 항목 많은 원그래프, 근거 없는 이중 축.

## 이 앱에서 그리는 법
- artifact.write type diagram에 Mermaid로 그린다.
  - 막대·선: `xychart-beta` (title, x-axis [..], y-axis "단위", bar [..] 또는 line [..])
  - 원: `pie title 제목` 다음 줄마다 `"항목" : 값`
- 보고서(type report·plan) 안에는 ```mermaid 블록으로 넣는다.
- 원본 숫자는 표로 함께 둔다(type sheet 또는 보고서 표). 그림만 남기지 않는다.

## 예
xychart-beta
  title "월별 가입자 (출처: 가입 시트, 2026-09 기준)"
  x-axis [7월, 8월, 9월]
  y-axis "명"
  bar [120, 135, 150]
(예시 숫자다. 실제 그림에는 확인한 데이터만 넣는다.)

## 원칙
- 제목에 핵심을 쓴다: "9월 가입자 11% 증가"가 "월별 가입자"보다 낫다(계산이 확인됐을 때만).
- 막대는 0에서 시작한다. 비교하는 그림끼리 축 범위를 맞춘다.
- 축 이름과 단위, 기간과 출처를 적는다.
- 색에만 의존하지 않는다(값 표시·이름표). 강조는 한 곳만.
- 정렬: 자연 순서(월·단계)가 없으면 값 순서.

## 내놓기 전
색 없이도 읽히는가, 제목이 발견을 말하는가, 단위가 있는가, 출처·기간이 있는가, 그림의 숫자가 표와 같은가.
