# 데이터 분석

## 1. 질문 정하기
- 규모: 빠른 답(지표 하나) / 분석(추세·비교·원인) / 보고서(방법·한계·제안까지).
- 필요한 것: 어떤 지표, 어떤 기준(집단·분류), 어떤 기간, 결과 형태(숫자·표·그림·글).
- 질문이 모호하면 해석을 적고 시작한다("지난주 = 10/1~10/7로 봄").

## 2. 데이터 모으기
- 앱 안의 기록: record.search로 sheet·report 산출물, 업무·회의 기록을 찾고 record.read로 원문을 읽는다.
- 프로젝트 파일(CSV·JSON 등): project.read 권한이 있을 때만 읽는다.
- 공개 자료: web.search → web.fetch로 읽고 주소와 읽은 날짜를 남긴다.
- 데이터가 없으면 멈추고 사용자에게 붙여넣기·파일 위치를 요청한다. **숫자를 지어내지 않는다.**

## 3. 분석
- 지표 계산, 기간·집단 비교, 추세·이상값 찾기. 복잡하면 작은 질문으로 나눠 하나씩 답한다.
- 계산은 sheet의 수식(셀 f)으로 둔다. 암산한 값을 확정 수치처럼 쓰지 않는다.
- 상관을 원인으로 쓰지 않는다. 다른 설명이 가능하면 함께 적는다.

## 4. 내놓기 전 확인
- 행 수가 말이 되는가, 빈 값이 결과를 흔드는가, 크기가 상식적인가.
- 시계열에 빠진 기간이 없는가, 부분합이 전체와 맞는가.
- 하나라도 걸리면 조사하고, 못 풀면 한계로 적는다. 더 엄격한 점검은 validate-data.

## 5. 결과
- 빠른 답: 답 한 줄 + 근거(어느 기록·시트·주소) + 계산 방법.
- 분석: 핵심 발견 먼저 → 표·그림 → 방법과 한계 → 다음에 볼 질문.
- 보고서: artifact.write type report(요약, 데이터 출처, 방법, 발견, 한계, 제안). 계산표는 type sheet, 그림은 data-visualization 스킬 참고.
- 가정은 "가정:"으로, 확인 못 한 것은 "미확인"으로 표시한다.
