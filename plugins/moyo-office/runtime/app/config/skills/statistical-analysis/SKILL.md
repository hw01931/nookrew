# 통계 분석

## 요약 통계
- 치우치지 않은 분포: 평균. 치우친 분포(매출·이용 시간): 중앙값. 둘 다 쓰고 차이를 보면 치우침이 보인다.
- 퍼짐: 표준편차(고른 분포), 사분위 범위(치우친 분포).
- 백분위로 설명한다: "중앙값은 4분, 상위 10%는 22분 이상".
- 분포는 모양·중심·퍼짐·이상값·하한/상한(0, 100%)으로 설명한다.

## 추세
- 이동 평균(일별 자료는 7일)으로 흔들림을 줄인다.
- 비교는 같은 길이·같은 시기끼리(전주 같은 요일, 전년 같은 달). 계절성이 있으면 전년 대비.
- 증가율 = (이번 - 이전) / 이전.
- 예측은 범위로 말한다("1만~1.2만 예상"). 한 숫자로 단정하지 않는다. 복잡하면 사람 전문가에게 넘긴다.

## 이상값
- 찾기: 사분위 범위 방법(Q1 - 1.5×IQR 미만, Q3 + 1.5×IQR 초과) 또는 상하위 1%.
- 바로 지우지 않는다. 입력 오류면 고치거나 빼고, 진짜 극단값이면 중앙값을 쓰고, 다른 집단이면 따로 분석한다.
- 무엇을 몇 건 뺐는지 적는다.

## 차이가 우연인가
- 귀무가설(차이 없음)과 유의수준(보통 0.05)을 먼저 정한다.
- 고르기: 두 집단 비율 → 비율 z 검정, 두 집단 평균 → t 검정, 같은 대상 전후 → 대응 t 검정, 치우친 자료 → 맨-휘트니, 분류 두 개의 관계 → 카이제곱.
- 이 앱에는 통계 계산기가 없다. 검정 통계량·p값을 지어내지 않는다. 계산은 sheet 수식(예: T.TEST, CHISQ.TEST)으로 두고 결과를 확인한 뒤에만 쓴다. 시트에서 계산되지 않으면 "미계산"으로 둔다.
- 통계적 유의와 실제 의미는 다르다. 효과 크기(몇 %p), 범위, 사업 영향을 함께 쓴다.
- 표본이 작으면 그렇게 밝힌다(집단당 수십 건 미만이면 결론을 약하게).

## 조심할 것
- 상관 ≠ 원인: 반대 방향, 제3의 요인, 우연을 생각한다.
- 여러 번 검정하면 우연히 유의한 것이 나온다. 몇 번 했는지 적는다.
- 합치면 뒤집히는 추세(심슨 역설): 주요 집단별로도 확인한다.
- 생존 편향, 집단 결과를 개인에 적용하기, 지나친 소수점("4.73%" 대신 "약 5%").
